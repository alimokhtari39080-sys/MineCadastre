# MineCadastre

نسخه اولیه وب‌اپلیکیشن نصب‌پذیر (PWA) برای نمایش آزمایشی محدوده‌های معدنی.

## انتشار در GitHub Pages
در مخزن به مسیر **Settings → Pages** بروید؛ گزینه **Deploy from a branch** را انتخاب کنید، شاخه `main` و پوشه `/(root)` را ذخیره کنید.

## امکانات نسخه آزمایشی
- نقشه تعاملی ایران و نمایش چند محدوده فرضی
- جست‌وجو و فیلتر بر اساس نام، ماده معدنی و وضعیت
- نمایش مختصات گوشه‌ها و مختصات کلیک روی نقشه
- مکان‌یابی دستگاه، لایه ماهواره‌ای و خروجی GeoJSON
- قابلیت نصب به‌صورت PWA روی گوشی

## هشدار مهم درباره داده‌ها
تمام محدوده‌ها، نام اشخاص، وضعیت‌ها و مختصات این نسخه صرفاً نمونه و فرضی هستند. این پروژه به کاداستر رسمی وزارت صمت، منابع طبیعی یا سرویس رسمی GIS متصل نیست. آزاد یا ثبت‌شده بودن هیچ محدوده‌ای را نمی‌توان بر اساس این نسخه تعیین کرد. برای استفاده عملی باید داده رسمی و به‌روز با مجوز دسترسی به سامانه متصل شود.

## فناوری‌ها
HTML، CSS، JavaScript، Leaflet، OpenStreetMap و PWA. بارگذاری نقشه و فونت به اینترنت نیاز دارد.
